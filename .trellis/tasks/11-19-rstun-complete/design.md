# 设计：完整 STUN 服务端

## 1. 边界

- 单进程、无外部依赖（除可选鉴权的共享密钥文件/环境变量）。
- **状态**：无会话状态；鉴权 nonce 用无状态构造（HMAC(secret, expiry|client_ip)），不落盘。
- **新增依赖**：尽量 0；HMAC-SHA1/SHA256 可用 `hmac` + `sha1`/`sha2`（纯 Rust，体积极小）。
  若必须引入，先评估「运行时依赖 ≤ 8 个」红线。

## 2. 关键取舍

| 主题 | 选择 | 理由 | 备选（弃） |
| --- | --- | --- | --- |
| 抗滥用 | 每源 IP 令牌桶 + 全局并发上限（`tokio::sync::Semaphore`） | 无状态、可配置、NAT 友好 | 按连接限速（UDP 无连接） |
| 反射放大 | 任何「改变目的」的属性（RESPONSE-PORT / CHANGE-REQUEST）要求请求 ≥ 最小尺寸，并纳入同一限速桶 | UDP 可伪造源，必须让放大比 ≤1 | 直接禁用（破坏 RFC 5780 价值） |
| 鉴权 | RFC 5389 短期（§10.1）+ 长期（§10.2）；RFC 8489 SHA256 作为可选 | 与 coturn 对齐，客户端认知成本低 | 只做长期（coturn 默认场景） |
| nonce | 无状态 HMAC，默认 1h 过期 | 多实例无需共享存储 | 内存表（重启失效、多实例不一致）|
| 观测 | 指标默认关闭；开启时独立 `--metrics-listen`（手写最小 HTTP/1.1 文本响应，无新依赖） | 保持「无 HTTP 面」默认 | 依赖 axum/hyper（依赖膨胀）|
| 配置 | CLI 保持唯一真源；新增可选的 env 映射（`RSTUN_*`） | 容器友好且不加解析依赖 | TOML/配置文件（需 serde）|
| TLS | 不做（属 TURN/turns 域） | 与 TURN 决策绑定 | 现在做（无消费方）|

## 3. 数据流（鉴权开启时）

```
UDP/TCP 收包 → 解析 → 方法/类判定 → 未知 comprehension-required → 420
  → 鉴权策略：
      - 无凭据配置：忽略 MI（现状）
      - 短期：校验 MESSAGE-INTEGRITY(HMAC-SHA1)，失败 → 401
      - 长期：无 MI → 401 + REALM/NONCE；有 MI 但 nonce 过期 → 438 + 新 nonce；校验失败 → 401
  → PADDING/RESPONSE-PORT 组合 → 400
  → 限速桶（源 IP）→ 超限静默丢弃（UDP）/ 关闭连接（TCP）
  → 编码响应 → 发送
```

## 4. 兼容性

- 无鉴权配置时行为与 `26.410.100` **逐字节一致**（冻结测试继续生效）。
- 新增属性（REALM/NONCE/ERROR 401/438）只在鉴权路径出现。
- ICE/鉴权已知属性白名单保持不变（避免 420 误伤）。

## 5. 回滚

每个子任务独立可回滚：鉴权与限速都由配置开关控制，默认关闭；打开后出问题可运行时关闭并重启。
