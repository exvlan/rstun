# TURN：`turns:` / DTLS 证书热加载（免重启）

## 背景

`--tls-cert` / `--tls-key` 目前在**启动时**解析一次（路径不可读、证书/私钥不配对、DTLS 算法不合法
都会导致启动失败）。证书轮换只能重启进程——对流量的影响是「监听器重建 + 所有 DTLS 会话中断」，
在 TURN 这种长连接场景里代价明显。

T2（`turns:`/DTLS）已归档，行为表现状写明「证书热加载：当前重启生效」，本任务即补齐该项。

## Goal

在**不重启、不中断监听**的前提下重新加载证书与私钥：

- `turns:`(TLS) 与 DTLS 监听**同时生效**；
- 新材料校验与启动时**同一套规则**（否则会出现「启动会拒绝、热载却接受」的双重标准）；
- 校验失败 → **保留旧材料**、服务继续、计数 +1、日志说明；
- 新连接使用新材料；已建立的 TLS/DTLS 会话按各自协议语义自然持有旧材料（写清，不承诺重协商）。

## 范围

1. **触发方式**（design 定）：
   - Unix：`SIGHUP`（运维惯例）；
   - 跨平台：检测两个路径的 `mtime`/size 变化（轮询，间隔可配或常量），覆盖 Windows 与「不想发信号」的场景；
   - 两者可同时存在，需去抖（避免先写 cert 后写 key 的中间态被判为坏材料）。
2. **校验**：复用启动时的解析与约束（`SecureMaterial` 的解析、证书/私钥配对、PKCS#8、
   DTLS 只接受 ECDSA P-256 / Ed25519）。任何一步失败 → 拒绝本次重载。
3. **原子替换**：TLS acceptor 与 DTLS 配置一次性切换到新 `Arc`；替换窗口内不允许出现「一半新一半旧」。
4. **可观测**：
   - 指标：重载成功/失败计数（固定标签集）；
   - 日志：成功（含文件路径与 mtime）与失败原因（不含私钥内容）；
   - **到期剩余时间（gauge）不在本版**：唯一的解析器 `x509-parser` 只是 `dtls` 的传递依赖，
     提升为直接依赖会让 tls-only 树多 27 条 lock、full 直接依赖 14→15，违反「不新增运行时依赖」。
     作为后续独立评估项（见 `design.md` D4）。
5. **文档**：`docs/book` 的 `turns:`/DTLS 章节、部署注意（`SIGHUP`/轮询）、README 摘要、spec、`CHANGELOG`。

## 非目标

- 不做 ACME/OCSP、不做 SNI 多证书、不做自动续期；
- 不支持运行期修改 `--tls-cert/--tls-key` 的**路径**（只重读同一路径）；
- 不改变未启用 TLS/DTLS 的构建行为（lean 构建完全不涉及）；
- 不做 RFC 6062 被动模式；
- 不发版（本任务与 RFC 6062 合并为下一个补丁版）。

## 约束（硬）

- **不新增运行时依赖**（`tokio` 的 `signal` feature 属于现有 crate；避免引入 `notify`/`inotify` 类库）。
- 指标必须遵守固定标签集（不得出现 per-file/per-path 标签）；`--turn`/TLS 未启用时不得输出这些指标。
- Windows/macOS/Linux 都能编译；非 unix 平台没有 `SIGHUP` 时靠轮询。
- 校验失败**绝不**降级为明文、也不关闭监听器（只保留旧材料）。
- 已有的 `handshake_failed` 先例：不需要进 `/metrics` 的信息只进日志。

## 验收

- [ ] 运行中替换证书链+私钥（同一路径）→ `openssl s_client` **新连接**看到新证书（序列号/`notAfter`）；
      已建立的连接不受影响；
- [ ] DTLS：`openssl s_client -dtls1_2` 新会话看到新证书；
- [ ] 坏材料（不配对 / RSA / 非 PKCS#8 / 截断）→ 旧证书继续服务、重载失败计数 +1、进程存活；
- [ ] 先写 cert 后写 key 的中间态不会被误判（去抖/两次校验）；
- [ ] `SIGHUP` 与轮询两条路径都能触发（在支持的平台上各验一次）；
- [ ] 指标：`rstun_turn_tls_reload_total{result=ok|failed}` 符合固定标签集；未启用 TLS 时不出现；
- [ ] 全量门禁绿（含 `cargo test --all-features`、lab `tls`/`dtls` 项、docs 校验）；
- [ ] 文档/spec/CHANGELOG 同步，写清「新连接用新证书、已有会话按协议语义」。
